# 보병 설계 — 추상화 회의 기록

> 시작: 2026-10-12. **아직 추상화 단계**(코드 · 부하 시험은 추상화가 끝난 뒤).
> 새 세션에서 이어 갈 때는 이 문서부터 읽고, 맨 아래 **열린 안건**부터 회의를 계속한다.

## 0. 게임 개요

- 횡스크롤 사이드뷰, 배경은 3D 맵, 캐릭터는 Dot Rigger 로 구운 2D 컷아웃 퍼펫.
- 워페어 1944 오마주. 단, 워페어의 **3열(각 열이 상대 열을 맡음) 시스템은 쓰지 않는다**(사용자 결정).

## 1. 사용자 결정 (10-12)

| 질문 | 결정 |
|---|---|
| 플레이어가 보병을 다루는 방식 | **둘 다** — 평소엔 지휘(투입 · 명령), 원하는 병사를 골라 **직접 조종(빙의)** |
| 한 화면 최대 병력 | **100명 이상** |
| 걸으면서 사격 | **특성 있는 유닛만 허용** — 나머지는 멈춰서 쏜다. 결국 "걸으며 쏘기"를 구조에 넣어야 함 |
| 상태머신 방식 | FSM 하나로 다 하지 않고 **두뇌(무엇을) + 몸(어떻게)** 2층 — 제안에 이견 없음 |
| 판단 단위 (안건 A) | **분대 두뇌 + 병사 실행** — 분대가 태세 · 목표 지점 · 엄폐 · 자리를 정하고, 병사는 실행(§2-7) |
| 분대 편성 (안건 A) | **고정 분대** — 투입 때 분대째로 나와 끝까지 같은 분대. 단독 병사 = 1인 분대 |
| 빙의 시 분대 (안건 A) | **나만 빠짐** — 분대는 하던 대로 AI, 빙의한 병사만 분대에서 빠져 단독 행동(제안은 "분대가 따라옴"이었음) |
| 사기 · 제압 수치 (안건 B) | **둘** — 제압 = 병사(순간), 사기 = 분대(오래감)(§2-8) |
| 무너지는 단계 (안건 B) | **후퇴 + 패주 + 패닉** 모두 지금 넣음(제안은 항복을 나중으로) |
| 항복 → 패닉 (안건 B) | 포로 처리 없음. **항복 대신 "패닉"** — 그 자리에서 통제 불능, 게임 흐름에선 무시(표적 후보 아님), 날아온 총알 · 폭발엔 맞아 죽을 수 있음 |
| 빙의 병사의 제압 (안건 B) | **AI 와 똑같이** — 넘치면 강제로 제압 상태, 조작이 잠깐 잠김(제안은 "조작은 안 뺏음") |
| 엄폐 인원 (안건 C) | **칸 수 제한** — 엄폐물 데이터에 칸 수(§2-9) |
| 엄폐 자세 (안건 C) | **높이마다 쏘는 · 숨는 자세 한 쌍** — 제압 = 숨는 자세로 강제 |
| 엄폐 파괴 (안건 C) | **지금은 안 부서짐** |
| 데이터 · 인스펙터 (요구) | 어느 상태에 어느 리소스(동작 · 장비 · 복장)가 쓰이는지 **인스펙터에서 보이고**, 값만 바꿔 끼울 수 있게(§2-11) |

## 2. 지금까지 정한 구조

### 2-1. 전장 모델 (열 대신)
- 위치 = **x(전선 방향) + 깊이(0~1 연속값)**. 깊이는 겹치지 않게 벌리기와 그리기 순서에만 쓴다.
- 사거리 · 표적 고르기는 **x 거리만**. 열이 없으니 사거리 안의 적은 모두 후보.
- 엄폐물 = **x 구간 + 높이(서서 / 앉아서 가림) + 막는 방향**. 참호 · 모래주머니는 깊이 전체를 덮는다.

### 2-2. 유닛 = 네 부분
1. **데이터** — 사거리 · 명중 · 속도 · 사기, 무기, 특성(걸으며 쏘기 등). Godot Resource.
2. **조종자** — 무엇을 할지 정함. AI 두뇌 또는 플레이어.
3. **몸** — 어떻게 움직일지. 상태머신.
4. **표현** — 퍼펫(동작 · 조준 · 장비 · 복장) · 소리 · 총구 불꽃. 논리 결과를 따라만 간다.

### 2-3. 조종자 (지휘 + 빙의)
```
지휘(분대 명령: 전진 · 정지 · 후퇴 · 목표 지역)
        │ AI 점수의 가중치로 들어감
분대 두뇌 (0.5~1초마다, 분대마다 하나 — §2-7)
        │ 태세 · 목표 지점 · 자리 — 이것도 가중치(강제 아님)
조종자 ─┬─ 병사 AI 두뇌 (0.2~0.5초마다 의도 후보에 점수 → 가장 높은 것)
        └─ 플레이어     (키보드 · 마우스)   ← 빙의 = 이 칸만 갈아 끼움 + 그 병사는 분대에서 빠짐
        │ 같은 형태의 "의도"를 냄: 이동 방향 · 자세 · 사격 대상(방향)
몸(상태머신) → 표현(퍼펫)
```
- 분대 태세 후보: 전진 · 유지 · 후퇴 · 돌격. 병사 의도 후보: 배정 자리로 이동 · 자리에서 사격 · 장전 · 투척(+ 자세).
- 점수 입력 — 분대: 지휘 명령 · 분대원 평균 제압 · 남은 인원 · 탄약 · 앞쪽 적 세기 · 가까운 엄폐 거리. 병사: 분대 지시 · 제압 · 체력 · 탄약 · 사거리 안 적.
- 명령은 강제가 아니라 가중치 → "명령받아도 제압당하면 못 나감" 같은 행동이 자연스럽게 나온다.
- 왜 FSM 하나가 아닌가: "무엇을 할지"까지 전이 조건으로 쓰면 상태가 늘 때마다 전이선이 폭발한다. 점수제는 행동 하나 = 점수 함수 하나.

### 2-4. 몸 상태머신 (두 영역 + 덮어쓰기)
```
몸
 ├─ 이동 영역:  서 있음 · 걷기 · 달리기 · 포복 · 엄폐 중
 ├─ 행동 영역:  없음 · 조준 · 사격 · 장전 · 투척 · 근접
 └─ 덮어쓰기:   피격 · 제압 · 패닉 · 사망   (두 영역 위에서 강제로)
```
- 두 영역은 **동시에** 돈다. "걸으며 쏘기" 특성이 없는 유닛은 규칙 하나: **행동 중이면 이동은 정지**.
- **자세(서기 · 앉기 · 엎드림)는 상태가 아니라 속성** — 상태 수가 곱으로 안 늘어난다.
- **제압은 두뇌보다 위의 끼어들기** — 총알이 가까이 지나가면 쌓이고, 넘치면 몸을 강제로 "제압" 상태로(워페어의 핵심 맛).

### 2-5. 표현 (퍼펫과의 연결)
- (이동, 행동, 자세) → **동작 이름 하나**를 표에서 찾는다(예: 걷기 + 사격 → `Walk+Fire`). 데이터 표라 그림이 바뀌어도 코드는 그대로.
- 지금 퍼펫 런타임(`DRPuppetSet`)은 **한 번에 동작 하나 재생 + 몸통 조준 각도**(+ 장비 · 복장). 상하체를 따로 재생하는 기능은 없다.
- → 걸으며 쏘기 조합은 Dot Rigger ① 의 **상하체 합성 굽기**(예: `Crouch_Idle+Firing_Rifle`)로 조합마다 굽는다(권장). 특성 유닛만 필요, 조합이 없으면 "멈춰서 쏘기"로 대체. 조합이 너무 많아지면 그때 퍼펫에 실시간 상하체 레이어를 넣는다(표현 층만 바뀜).

### 2-6. 100명 이상 대비
- 논리는 **중앙 전장 관리자**가 병사 기록을 배열로 들고 돈다(병사마다 논리 노드를 두지 않음).
- 상태 객체는 **모든 병사가 공유**(종류별 하나). 병사는 "지금 상태 번호 + 타이머"만 가진다. 상태를 노드로 만들지 않는다(100명 × 10상태 = 노드 1000개).
- 두뇌 판단은 **프레임마다 일부 병사씩 나눠서**.
- 조회는 x 를 **구역(예: 4 m)**으로 나눠 "사거리 안 적 · 총알 경로 근처(제압)"를 근처 구역만 본다.
- 총알은 물리 물체가 아니라 **즉시 판정 + 예광 그림**.
- **가장 큰 위험 = 퍼펫 100개 이상 그리기**(퍼펫 하나에 뼈 15 · 그림 약 30장). 대책 후보: 화면 밖 애니 멈춤, 먼 병사는 갱신 줄이기, 필요하면 스프라이트 시트. 표현 층을 갈아 끼울 수 있게 둔다.

### 2-7. 분대 (안건 A — 10-12 결정)
- **분대 두뇌**(0.5~1초마다, 분대마다 하나): 태세(전진 · 유지 · 후퇴 · 돌격) · 목표 지점(x) · 쓸 엄폐물 **예약** · 병사별 자리 배정.
  - 무거운 조회(엄폐 찾기 · 앞쪽 적 세기)는 **분대 수만큼만** 돈다(100명 ÷ 5~7명 ≈ 15~20개).
- **병사 두뇌**(0.2~0.5초마다, 가벼운 판단만): 배정된 자리로 이동 · 자세 · 표적 · 사격 · 장전 · 투척 타이밍. 분대 지시도 **가중치**.
- **멈칫이 저절로 나옴**: 제압된 병사는 못 나감 → 분대 평균 제압이 오름 → 분대 전진 점수가 내려감. 규칙을 따로 넣지 않는다.
- **흩어진 분대 모으기**: 앞선 병사와 뒤처진 병사 간격이 벌어지면 분대 전진 점수를 깎음 → 분대가 기다린다.
- **표적은 분대가 정하지 않는다** — 분대끼리 표적을 짝지으면 워페어의 열 시스템으로 되돌아간다. 병사가 사거리 안 적 아무나 고름. "집중 사격" 명령은 나중에 가중치로 얹을 수 있음.
- **고정 편성**: 투입 때 분대째로 나와 끝까지 같은 분대. 저격수 · 낙오자 = 1인 분대, 기관총조 = 2인 분대(역할: 사수 · 부사수). 분대 크기 · 역할은 병종별 데이터.
- **엄폐 예약**: 분대가 엄폐물을 예약하고 자리를 나눠 줌 → 안건 C 의 인원 제한 = 예약 칸 수.
- **빙의 = 나만 빠짐**: 빙의한 병사는 분대에서 빠져 단독 행동, 분대는 하던 대로 AI.
  - (기본값 제안) 빙의 중엔 그 병사를 분대의 인원 · 자리 · 평균에서 뺀다.
  - (기본값 제안) 빙의를 풀면 원래 분대로 복귀 — 분대 자리로 걸어감(흩어진 분대 모으기 규칙 그대로). 원래 분대가 전멸했으면 1인 분대.

### 2-8. 사기 · 제압 (안건 B — 10-12 결정)
- **제압 — 병사, 순간**: 근처로 지나가는 총알 · 폭발로 쌓이고 몇 초 만에 빠진다. 넘치면 몸 덮어쓰기 "제압"(§2-4).
- **사기 — 분대, 오래감**: 분대원 사상 · 제압이 오래 이어짐 · 고립 · 장교 근처 · 적 분대 격파 등으로 오르내린다. 분대 두뇌 점수 입력.
- **연결**: 사기가 낮으면 제압이 빨리 쌓이고 늦게 빠진다.
- 하나로 합치지 않는 이유: "잠깐 엎드림"(제압)과 "분대가 무너짐"(사기)을 구분하려고.
- **무너지는 단계**
  1. **후퇴** — 분대 두뇌가 스스로 고르는 태세. 질서 있게 뒤쪽 엄폐로.
  2. **패주** — 사기 바닥. **분대 단위 덮어쓰기**(두뇌보다 위): 명령 무시 · 사격 없이 뒤로 달림 · 사기가 회복되면 재집결.
  3. **패닉**(항복 대신 — 사용자 결정) — 병사 단위 몸 덮어쓰기. 그 자리에서 웅크려 통제 불능, **게임 흐름에선 무시**(표적 후보 아님 · 포로 처리 없음).
     - 날아온 총알 · 폭발엔 맞아 죽을 수 있다 — 빗나간 사격의 경로 근처면 맞을 수 있음(제압용 "경로 근처" 조회를 그대로 씀. 확률은 안건 D).
     - (기본값 제안) 언제: 패주 중인데 적이 가깝거나 뒤가 막혔으면(포위 · 맵 끝). 회복 없음 — 분대는 사상자처럼 센다(사기에 반영).
- **빙의 병사**: 제압은 AI 와 똑같이(넘치면 강제 제압, 조작 잠깐 잠김).
  - (기본값 제안) 분대에서 빠져 있으니 분대 사기와 무관 → 패주 · 패닉 없음, 제압 쌓이는 속도는 보통 사기 기준.
  - (제안) 제압 상태는 짧게(몇 초) + 화면에 제압 게이지 — 잠기는 순간을 예상할 수 있게.
- **표현에 늘어나는 동작**: 패닉 웅크림 1 개. 패주 달리기는 지금 있는 Sprint 로 대신.
- "장교 근처"가 사기 입력에 있으니 장교 병종이 생긴다 → 안건 E(투입)에서 같이.

### 2-9. 엄폐 (안건 C — 10-12 결정)
- **칸 수 제한**: 엄폐물 데이터에 칸 수(길이로 기본값, 손으로 고칠 수 있음). 분대가 칸을 예약(§2-7). 칸을 못 얻은 분대는 다른 엄폐를 찾거나 엄폐 없이 엎드림.
- **높이마다 쏘는 · 숨는 자세 한 쌍**:

  | 엄폐 | 쏘는 자세(조금 드러남) | 숨는 자세(거의 안 드러남, 못 쏨) |
  |---|---|---|
  | 없음 | 아무 자세(엎드리면 표적이 작아짐) | 엎드림 |
  | 낮음(모래주머니 · 낮은 담) | 앉기 | 엎드림 |
  | 높음(참호 · 벽) | 서기 | 앉기 |

- **제압 = 숨는 자세로 강제** → 제압당한 분대는 사격이 끊기고, 그 사이 상대가 전진한다.
- 가림 정도는 숫자(시험하며 맞춤). 명중 확률에 곱할지 맞는 부위를 가릴지는 안건 D.
- (기본값) **막는 방향** = 앞만 / 양쪽. 모래주머니 = 앞만, 참호 = 양쪽(빼앗은 쪽도 씀). "앞만"은 반대쪽 x 에서 쏘면 무효.
- **지금은 안 부서짐**. 분대 두뇌가 매번 엄폐를 다시 고르니 나중에 파괴를 넣어도 논리는 거의 그대로 — 비용은 3D 맵 쪽 그림.

### 2-10. 그래서 FSM 인가, 비헤이비어 트리인가 (10-12 사용자 질문)
- **둘 중 하나가 아니라 층마다 다르다.**

  | 층 | 기법 |
  |---|---|
  | 분대 두뇌 · 병사 두뇌 | **점수제(Utility AI)** — 후보마다 점수, 가장 높은 것 |
  | 몸 | **FSM** — 이동 · 행동 두 영역이 동시에(병렬) + 덮어쓰기 |
  | 제압 · 패주 · 패닉 | 덮어쓰기 — 두뇌보다 위에서 강제 |

- **비헤이비어 트리(BT)**: "조건 → 순서 → 행동"을 나무 모양으로 짜 두고 매번 위에서부터 훑어 처음 통과하는 가지를 실행. 우선순위가 **나무 모양 자체로 고정**. 몇 안 되는 적이 정교한 순서 행동을 할 때(액션 게임의 경비병 · 보스) 강하다.
- 두뇌를 BT 로 하지 않는 이유:
  1. 이 게임의 맛("명령은 가중치", "제압당하면 못 나감")은 여러 사정을 **저울질**하는 것. BT 는 정해진 순서로 고르는 도구라, 저울질을 넣으려면 결국 점수를 다시 만들게 된다.
  2. 100명 이상 — 병사 판단은 짧고 가벼워야 함(자리 · 자세 · 표적 · 장전). BT 의 장점(긴 순서 행동)이 쓰일 데가 적다.
  3. BT 가 더 "고급"인 것은 아니다 — 문제 모양에 맞춰 고르는 도구.
- **써 보고 싶으면 자리는 있다**: 두뇌는 갈아 끼우는 칸(빙의 = 플레이어로 교체하는 것과 같은 구조)이라, 특수 병종 하나(예: 기관총조의 "자리 잡기 → 거치 → 사격 → 탄 갈기" 같은 순서 행동)의 두뇌만 BT 로 시험할 수 있다. 본 구조는 그대로.

### 2-11. 데이터와 인스펙터 (10-12 사용자 요구)
> "어느 리소스가 들어가 있고, 어느 상태일 때 어느 리소스가 쓰이는지 인스펙터에서 보여야 한다(유니티 솔저 프리팹처럼). 나중엔 값만 바꿔 끼울 수 있게."

- **유니티 프리팹 자리 = 병종 리소스(`.tres`)**. Godot Resource 는 인스펙터에 그대로 보이고, 끌어다 놓아 바꿔 끼우며, 여러 병사가 같이 쓴다(유니티 ScriptableObject 와 같은 성격).
  - 살아 있는 병사 하나하나는 노드가 아니라 기록(§2-6) → 인스펙터로 고치는 대상은 **병종**. `소총수.tres` 를 고치면 모든 소총수가 바뀐다.
- 병종 리소스 모양(예시):
  ```
  소총수.tres (병종)
  ├─ 능력치   사거리 · 명중 · 속도 · 체력 · 제압 내성
  ├─ 특성     [ ] 걸으며 쏘기 …
  ├─ 분대     기본 인원 · 역할
  ├─ 무기     kar98k_무기.tres   ← 끌어다 놓기(탄창 · 연사 · 사거리 + 장비 DREquipSet)
  ├─ 외형     퍼펫 세트 · 복장(DROutfit)
  └─ 동작 표  소총수_동작.tres   ← 다른 병종과 공유 가능
  ```
- **동작 표**(§2-5 의 표를 인스펙터로, 동작 이름은 예시):
  ```
  상태 조합                    동작
  서 있음 · 없음               Idle
  걷기 · 없음                  Walk
  걷기 · 사격 (특성)           Walk+Fire     ⚠ 세트에 없음 → 멈춰서 쏘기로 대체
  엄폐(낮음) · 쏘기            Crouch_Fire
  엄폐(낮음) · 숨기 / 제압     Prone_Idle
  엄폐(높음) · 쏘기            Firing_Rifle
  패닉                         Cower         ⚠ 아직 안 구움
  ```
  - 동작 칸은 **연결된 퍼펫 세트에 실제로 구워진 동작 중에서 고르는 목록**(오타 방지).
  - 세트에 없는 동작은 **경고 + 대체 동작** → 무엇을 더 구워야 하는지 표에서 바로 보인다.
  - 이 표 모양은 Godot 기본 인스펙터로는 읽기 어려워 **전용 인스펙터 화면**(Dot Rigger 처럼 에디터 플러그인)으로 만든다.
- **실행 중 확인**: 게임 실행 중 병사를 고르면 "지금 상태 · 지금 동작 · 표의 어느 줄 · 제압 · 분대 사기"를 보여 주는 디버그 패널.
- 조정은 코드 없이 리소스만: 숫자 바꾸기 · 무기 / 복장 끌어다 바꾸기 · 동작 표 줄 바꾸기.
