## 검증

렌더가 필요한 도구는 **창이 잠깐 떴다 닫힌다.** `--headless` 로는 SubViewport 가 안 그려져서 쓸 수 없다(`bake_cli --diag` 만 예외). 출력을 받으려면 `_console.exe` 를 쓴다.

**Git Bash**
```bash
G="/c/<경로>/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64_console.exe"
P="C:/<경로>/SideProject"

"$G" --headless --path "$P" --import                                                     # ① 스크립트 등록 (새 class_name 추가 후에도 필수)
"$G" --headless --path "$P" --script res://addons/dot_rigger/tools/bake_cli.gd -- --diag   # ② 본→파트 매핑
"$G" --headless --path "$P" --script res://addons/dot_rigger/tools/unit_page_smoke_cli.gd         # ③ ① 유닛 탭(10-16 — 예전 2D 캐릭터 굽기 창의 ui_smoke_cli 는 창과 함께 지움)
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/rootbone_check_cli.gd # ④ 파트 피벗
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/drift_check_cli.gd    # ⑤ 자세 고정
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/layer_check_cli.gd    # ⑥ 발(발가락 합침)/레이어
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/anim_merge_check_cli.gd # ⑦ 같은 폴더에 여러 번 구우면 애니가 쌓이는지
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/sets_check_cli.gd       # ⑧ 리깅 애니메이션 세트 베이크
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/planar_check_cli.gd     # ⑨ 동작 평면화
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/retarget_check_cli.gd   # ⑩ Mixamo 접목 (source3d 없으면 건너뜀)
"$G" --path "$P" --resolution 400x300  --script res://addons/dot_rigger/tools/composite_check_cli.gd  # ⑪ 상하체 합성
"$G" --path "$P" --resolution 900x700  --script res://addons/dot_rigger/tools/pixel_check_cli.gd      # ⑫ 도트 격자 고정 (창이 900x700 이상이어야 함)
"$G" --path "$P" --resolution 900x700  --script res://addons/dot_rigger/tools/puppet_set_check_cli.gd # ⑬ 런타임 DRPuppetSet (세트 묶기 · 조준 · 장비)
"$G" --headless --path "$P" --script res://addons/dot_rigger/tools/equip_page_smoke_cli.gd                   # ⑭ ② 장비 탭(3D 뼈 소켓, 10-16 — 예전 2D 장비 굽기 창 검사는 창과 함께 지움)
"$G" --headless --path "$P" --script res://addons/dot_rigger/tools/outfit_page_smoke_cli.gd                  # ⑮ ③ 복장 탭(3D, 10-16 — 예전 2D 복장 굽기 창 검사 ⑮ ⑯ ⑰ 는 창과 함께 지움)
"$G" --headless --path "$P" --script res://addons/dot_rigger/tools/hub_smoke_cli.gd                          # ⑲ Dot Rigger 창(탭 3 · Ctrl+숫자, 창 없이 — 창으로 돌리면 그림도)
"$G" --headless --path "$P" --script res://game/tools/view3d_smoke.gd -- --seconds=60 --squads=2 --seed=1941  # ㉑ 3D 게임 화면(병사 · 동작 · 소켓 무기 · 왼손 IK · 조준 IK)
"$G" --headless --path "$P" --script res://addons/dot_rigger/tools/aim_check_cli.gd                         # ㉒ 조준 IK(10-21 — 사격 때 허리 · 가슴으로 총구를 표적에)
"$G" --headless --path "$P" --script res://addons/dot_rigger/tools/hit_check_cli.gd                         # ㉔ 피격 반응(10-21 — IK 피격 · 시뮬 피격 신호)
"$G" --headless --path "$P" --script res://game/tools/equip_smoke.gd                                        # ㉓ 안건 F — 수정자 · 운용 장비(MG42) · 섞인 분대(10-21)
python pipeline/check_editor.py --headless --sandbox=<저장소 통째 사본>                                       # ⑳ 실제 에디터 안 검사(창 없이 — 사본 project.godot 에 탐침을 잠깐 넣음)
python pipeline/check_character.py source3d/characters/uniform_m36/uniform_m36.glb [--rest_time 0.42]      # ⑱ 캐릭터 실제 굽기 비교(샌드박스 Documents/1941 에서 돌림)
```
